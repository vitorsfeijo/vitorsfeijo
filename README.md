### 🚀 Projetos em Destaque

#### 🎓 [Ciência da Computação — UFRGS](https://github.com/vitorsfeijo/Ciencia_da_Computacao_UFRGS)
Repositório centralizado documentando minha trajetória acadêmica na UFRGS (1º ao 4º semestre), contendo implementações em C, C++, Python, Java, Verilog, simuladores de hardware, sistemas de arquivos e bancos de dados.

#### 🗄️ [Sistema de Banco de Dados Relacional (PostgreSQL)](https://github.com/vitorsfeijo/Ciencia_da_Computacao_UFRGS/tree/main/4_Quarto_Semestre/Bancos_de_Dados)
Modelagem conceitual e lógica completa para plataformas de jogos e e-sports (estilo Steam). Inclui DDL com regras de integridade, scripts DML com parser JSON automatizado em Python e dezenas de consultas analíticas avançadas.

#### 🖥️ [Microarquitetura RISC-V & Simulação gem5](https://github.com/vitorsfeijo/Ciencia_da_Computacao_UFRGS/tree/main/4_Quarto_Semestre/Organizacao_de_Computadores)
Projeto do datapath RV32I e exploração do espaço de projeto arquitetural utilizando o simulador industrial **gem5**, analisando o impacto de IPC, hierarquias de memória cache e preditores de desvio sob benchmarks reais em C.

#### 🐧 [Sistema de Arquivos SOFS & Concorrência](https://github.com/vitorsfeijo/Ciencia_da_Computacao_UFRGS/tree/main/4_Quarto_Semestre/Sistemas_Operacionais)
Implementação de um sistema de arquivos baseado em inodes/blocos com suporte a FUSE e resolução de problemas de sincronização multithread com **POSIX Threads** e semáforos no ambiente Linux.
